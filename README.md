# Arrow Game

这是一个使用 Python 和 Pygame 开发的“一箭又一箭”风格小游戏，作为软件工程课程第二次作业项目。

## 当前阶段

第 2 阶段：棋盘和四方向箭头显示。

当前版本包含：

- Pygame 初始化
- 标题为 `Arrow Game` 的基础窗口
- 基础游戏主循环
- 点击窗口关闭按钮退出程序
- 6×6 网格棋盘
- 上、下、左、右四种方向的测试箭头

鼠标点击、路径检测、箭头移动、关卡、碰撞和失误机制将在后续阶段逐步开发。

## 环境要求

- Python 3.13 或兼容版本
- Pygame 2.6.1

## 安装依赖

```powershell
python -m pip install -r requirements.txt
```

## 运行程序

```powershell
python main.py
```

## 开发记录

本项目采用分阶段开发方式。每个阶段完成后记录实现内容、测试结果和后续计划。
